## About

I build at the intersection of **research** and **production engineering** — training vision models for medical imaging, then interrogating *why* they made the call. Most of my work lives in two places: attribution and reliability analysis for deep vision models, and agentic LLM systems that have to survive contact with real users.

```python
class AyushmanBhatt:
    role     = "AI Research Engineer & LLM Systems Developer"
    focus    = ["Explainable AI", "Medical Imaging", "Agentic AI", "LLM Engineering"]
    digging  = ["XAI attribution", "shortcut learning", "vision transformers",
                "multi-agent architectures", "model reliability"]
    shipping = ["SmartAMR — AMR treatment recommendation",
                "LangGraph agent workflows", "RAG pipelines",
                "histopathology DL pipelines"]
    thesis   = "Accuracy is table stakes. Interpretable and auditable is the bar."
```

**Three principles I build against:**

| | |
|---|---|
| **Interpretability isn't optional** | Black-box accuracy doesn't clear the bar in high-stakes domains. *Why* a model decided matters as much as *what* it decided. |
| **Reliability must be measurable** | Shortcut learning, distribution shift, and spurious correlations aren't edge cases in deployment — they're the default. |
| **Research leads deployment** | Engineering without research intuition produces brittle systems. First principles before implementation. |
